# Северный парк — сайт жилого комплекса

Демо-проект для портфолио: застройщик и ЖК вымышленные, заявки никуда не отправляются.
Каталог из 420 квартир, фильтры, шахматка, страницы квартир с SVG-планировками и ипотечный калькулятор.

**Демо:** https://nkorshun-realestate.netlify.app

## Скриншоты

- `docs/home.png` — главная (место для скриншота)
- `docs/catalog.png` — каталог с фильтрами
- `docs/flat.png` — страница квартиры
- `docs/chessboard.png` — шахматка

## Возможности

- Каталог: мультивыбор комнатности, двойные ползунки цены и площади, этаж, корпус, срок сдачи, отделка, особенности; сортировка; карточки или таблица; пагинация по 24; избранное и сравнение до 3 квартир (localStorage).
- Фильтры целиком в URL (`/flats/?rooms=1,2&priceMax=300000`): ссылка открывает то же состояние, «Назад» работает.
- Страница квартиры `/flats/[id]/`: SVG-планировка, схема этажа, характеристики, ипотека с подставленной ценой, похожие квартиры, форма брони.
- Шахматка корпусов с фильтром по комнатности, клавиатурой и боковой карточкой.
- Ипотека: аннуитет и дифференцированный платёж, график по месяцам, график остатка долга, программы банков.
- Цены в BYN или USD по фиксированному курсу из данных.
- SEO: Metadata API, Open Graph, canonical, JSON-LD (`ApartmentComplex`, `Apartment` + `Offer`), sitemap со всеми квартирами, robots.

## Стек

Next.js (App Router) + TypeScript strict + CSS Modules, статический экспорт. Vitest для тестов. Без UI-библиотек.

## Архитектура

- **Генерация квартир.** `src/lib/generate-flats.ts` проходит по корпусам, подъездам, этажам и 4 позициям на этаже, берёт типовую планировку из `src/data/buildings.ts` и считает цену, статус и особенности. Генератор случайных чисел с фиксированным зерном, поэтому результат всегда одинаковый — это важно для статического экспорта и стабильных ссылок.
- **Фильтры в URL.** `src/lib/filters.ts` — чистые функции: `parseFilters`, `filtersToParams`, `applyFilters`, `sortFlats`. Компонент `Catalog` читает `useSearchParams()` (внутри `Suspense`) и пишет через `router.push`. Счётчик на главной вызывает ту же `applyFilters`, поэтому числа совпадают.
- **Статический экспорт страниц квартир.** `generateStaticParams` возвращает все 420 id, `dynamicParams = false`. В `out/flats/<id>/index.html` лежит готовый HTML с уникальными title, description и JSON-LD, поэтому поисковики видят контент без JavaScript.
- **SVG-планировки.** `src/data/layouts.ts` описывает 12 типовых планировок как два ряда комнат (метры). `LayoutSvg` рисует комнаты, подписи с площадями, окна, двери, балкон или лоджию. Площадь квартиры — сумма площадей комнат, поэтому подписи всегда сходятся с итогом.
- **Ипотека.** `src/lib/mortgage.ts` — чистые функции без React. Формула аннуитета: `P·r / (1 − (1+r)^−n)`, дифференцированный платёж: `P/n + остаток·r`.
- **Серверные и клиентские компоненты.** Контент и страницы квартир — серверные. Клиентские: фильтры, шахматка, калькулятор, формы, галерея, избранное и сравнение.

## Где менять данные

| Что | Файл |
| --- | --- |
| Базовая цена за м², доли статусов, поправки | `src/lib/generate-flats.ts` |
| Корпуса, этажность, сроки, раскладка планировок по подъездам | `src/data/buildings.ts` |
| Планировки и комнаты | `src/data/layouts.ts` |
| Курс USD, контакты, тексты, новости, ход строительства, банки | `src/data/complex.ts` |
| Адрес сайта для canonical и sitemap | переменная `NEXT_PUBLIC_SITE_URL` |

## Запуск

```bash
npm install
npm run dev       # http://localhost:3000
npm run lint
npm test          # Vitest
npm run build     # статика в папке out/
```

## Тесты

`npm test` проверяет ипотеку (аннуитет и дифференцированный платёж против ручных формул, сумма графика = кредит + переплата), детерминизм генерации и доли статусов, фильтры и их путь через URL, маску телефона и валидацию.

## Деплой на Netlify

1. Загрузите проект в репозиторий и подключите его в Netlify (или перетащите папку `out` после `npm run build`).
2. Настройки берутся из `netlify.toml`: команда `npm run build`, публикация из `out`.
3. В переменных окружения задайте `NEXT_PUBLIC_SITE_URL` (адрес сайта без слэша в конце), чтобы canonical и sitemap были верными.
4. Страницы квартир открываются по прямой ссылке: у каждой своя папка с `index.html`.
